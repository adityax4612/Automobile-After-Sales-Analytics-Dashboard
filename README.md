# 🚗 Automobile After-Sales Analytics

> **An advanced, decision-intelligence-driven dashboard for automotive service operations, revenue tracking, and customer retention analysis.**

## 📌 Project Overview

**Automobile After-Sales Analytics** is a comprehensive, interactive business intelligence dashboard designed to transform raw automotive service data into actionable strategic insights. 

Built using **Streamlit** and **Plotly**, the application processes over 2,000 service records to provide real-time telemetry on revenue streams, brand performance, warranty exposure, and customer behavior. Unlike traditional static reports, this dashboard features a **Decision Intelligence Engine** that automatically surfaces critical business anomalies, revenue champions, and operational risks.

## 🏆 Key Differentiators

1. **Decision Intelligence Engine:** Auto-generates strategic insights (e.g., identifying the highest warranty-risk brand or the most profitable service type dynamically based on filters).
2. **Interactive Command-Room UI:** Features a custom dark-themed, glassmorphic sidebar with live record-count telemetry and categorized filter groups.
3. **Multidimensional Heatmaps:** Visualizes revenue concentration across Brand × Service Type matrices.
4. **Customer Retention Mapping:** Plots Average Rating vs. Repeat Customer Rate with revenue-weighted bubble sizing to identify true brand loyalty.

## 🛠️ Technology Stack

| Component | Technology | Purpose |
